# ls

## 常用场景
- 列出目录内容
- 查看文件详细信息
- 查找文件

## 功能说明
ls 是英文单词 list 的简写，其功能为列出目录的内容，是用户最常用的命令之一，它类似于 DOS 下的 dir 命令。

## 文件命名规则
- Linux 文件或者目录名称最长可以有 256 个字符
- `.` 代表当前目录
- `..` 代表上一级目录
- 以 `.` 开头的文件为隐藏文件，需要用 `-a` 参数才能显示

## 常用命令
```bash
ls                      # 列出当前目录内容
ls -l                   # 以列表方式显示文件的详细信息
ls -lh                  # 配合 -l 以人性化的方式显示文件大小
ls -la                  # 显示所有文件，包括隐藏文件
ls -lt                  # 按时间排序
ls -R                   # 递归显示
```

## 常用参数
- `-a`: 显示指定目录下所有子目录与文件，包括隐藏文件
- `-l`: 以列表方式显示文件的详细信息
- `-h`: 配合 -l 以人性化的方式显示文件大小（KB, MB, GB）
- `-t`: 按时间排序
- `-R`: 递归显示子目录

## 输出信息说明
使用 `ls -l` 时，列出的信息包括：
- 文件权限
- 链接数
- 所有者
- 所属组
- 文件大小
- 修改时间
- 文件名

## 通配符

### 基本通配符
在 Unix/Linux 系统中，允许使用特殊字符来同时引用多个文件名，这些特殊字符被称为通配符。

| 通配符 | 含义 | 示例 |
|--------|------|------|
| `*` | 文件代表文件名中所有字符 | `ls te*` 查找以 te 开头的文件<br>`ls *html` 查找结尾为 html 的文件 |
| `?` | 代表文件名中任意一个字符 | `ls ?.c` 只找第一个字符任意，后缀为 .c 的文件<br>`ls a.?` 只找只有 3 个字符，前 2 字符为 a.，最后一个字符任意的文件 |
| `[]` | 将字符组括起来，表示可以匹配字符组中的任意一个 | `ls [abc]*` 匹配 a、b、c 中的任意一个开头的文件<br>`ls [a-f]*` 匹配从 a 到 f 范围内的任意一个字符开头的文件 |
| `-` | 在方括号内用于表示字符范围 | `[a-f]` 匹配从 a 到 f 范围内的任意一个字符 |
| `\` | 转义字符，使通配符作为普通字符使用 | `ls \*a` 查找文件名为 *a 的文件 |

### 通配符示例
```bash
# 查找以 te 开头的文件
ls te*

# 查找结尾为 html 的文件
ls *html

# 查找第一个字符任意，后缀为 .c 的文件
ls ?.c

# 查找只有 3 个字符，前 2 字符为 a.，最后一个字符任意的文件
ls a.?

# 查找从 a 到 f 范围内的任意一个字符开头的文件
ls [a-f]*

# 查找文件名为 a-f 的文件（- 在方括号外失去通配符作用）
ls a-f

# 查找文件名为 *a 的文件（转义字符）
ls \*a
```

### 注意事项
- `?` 和 `*` 处于方括号内时不用使用转义字符就失去通配符的作用
- 如果要使通配符作为普通字符使用，可以在其前面加上转义字符 `\`

## 其他常用参数
- `-R`: 递归显示子目录
- `-F`: 在文件名后添加文件类型标识符（/ 表示目录，* 表示可执行文件）
- `-d`: 只显示目录本身，不显示目录内容
- `-ld`: 以列表形式显示目录本身的信息

## 实战示例
```bash
# 基本用法
ls
ls -l
ls -a

# 人类可读格式
ls -lh

# 包含隐藏文件
ls -la
ls -all

# 递归显示
ls -R

# 显示文件类型
ls -F

# 只显示目录
ls -d */
ls -ld home

# 通配符
ls *.txt
ls [a-z]*.sh
ls -lh /var/log
ls -lt | head -10
```
