# jobs / bg / fg

## 常用场景
- 后台运行任务
- 管理后台任务
- 将前台任务切换到后台

## 常用命令
```bash
command &              # 将命令在后台执行
jobs                    # 查看后台运行的程序
fg %1                   # 将后台程序调出到前台（编号为通过 jobs 查看的编号）
bg %1                   # 将暂停的后台任务继续在后台运行
nohup command &         # 后台运行并忽略挂起信号
```

## 后台任务管理

### 将前台任务调入后台
1. **方法一**：在命令后加 `&`，直接后台执行
   ```bash
   python script.py &
   ```

2. **方法二**：如果程序已经在执行，按 `Ctrl+Z` 可以将程序暂停并调入后台

### 查看后台任务
```bash
jobs                    # 查看所有后台任务
jobs -l                 # 显示任务 PID
```

### 恢复后台任务
- `fg %n`: 将编号为 n 的后台任务调到前台执行
- `bg %n`: 将编号为 n 的后台任务在后台继续运行

## 常用参数
- `&`: 后台运行符号
- `nohup`: 忽略挂起信号，终端关闭后任务继续运行

## 易错点
- 后台任务在终端关闭时会终止（除非使用 nohup）
- 使用 nohup 或 screen/tmux 保持运行
- jobs 显示的编号是任务编号，不是进程 PID

## 实战示例
```bash
# 后台运行
python script.py &
sleep 100 &

# 查看后台任务
jobs

# 恢复任务到前台
fg %1

# 继续后台运行
bg %1

# 后台运行并保存输出
nohup python long_task.py > output.log 2>&1 &
```
