## 自动补全

### 功能
在敲出命令的前几个字母的同时，按下 `Tab` 键，系统会自动帮我们补全命令。

### 使用方法
1. 输入命令的前几个字母
2. 按下 `Tab` 键
3. 如果只有一个匹配，自动补全
4. 如果有多个匹配，按两次 `Tab` 显示所有匹配

### 示例
```bash
# 输入 ls 后按 Tab，可能补全为 ls -l
ls<Tab>

# 输入 cd /u 后按 Tab，可能补全为 cd /usr
cd /u<Tab>
```

## 终端快捷键

### 剪切和删除
- `Ctrl+u`: 剪切光标处到行首的所有字符（也就是删除）
- `Ctrl+k`: 剪切光标处到行尾的所有字符
- `Ctrl+w`: 剪切光标前的一个单词（word）
- `Ctrl+h`: 删除光标前的一个字符（相当于退格键）

### 中断
- `Ctrl+c`: 中断终端正在执行的任务并开启一个新的一行

### 光标移动
- `Ctrl+a`: 光标回到行首
- `Ctrl+e`: 光标回到行尾
- `Ctrl+f`: 光标向右移动一个字符（forwards）
- `Ctrl+b`: 光标向左移动一个字符（behind）
- `Esc+b`: 移动到当前单词的开头
- `Esc+f`: 移动到当前单词的结尾
- `Esc+t`: 当前单词向前移动

## 命令提示符

### 提示符格式
Linux 命令提示符的格式通常为：`[用户名@主机名 当前目录]提示符`

例如：`[root@localhost ~]#`

### 各部分含义
- `[]`: 提示符的分隔符号，没有特殊含义
- `root`: 显示的是当前的登录用户，目前使用的是 root 用户登录
- `@`: 分隔符号，没有特殊含义
- `localhost`: 当前系统的简写主机名（完整主机名是 localhost.localdomain）
- `~`: 代表用户当前所在的目录，此例中用户当前所在的目录是家目录
- `#`: 命令提示符。超级用户是 `#`，普通用户是 `$`

### 命令基本格式
```bash
[用户名@主机名 当前目录]提示符 command命令 [选项options] [参数parameter]
```

## 历史命令

### 查看历史
当系统执行过一些命令后，可按上下键翻看以前的命令。

### history 命令
`history` 将执行过的命令列举出来。

### 常用操作
- `history`: 查看所有历史命令
- `!!`: 执行上一条命令
- `!n`: 执行历史第 n 条命令
- `!string`: 执行最近一条以 string 开头的命令
- `Ctrl+r`: 搜索历史命令（交互式搜索）
- `上下箭头键`: 浏览历史命令

### 历史文件
- 历史命令保存在 `~/.bash_history` 文件中
- 可以通过环境变量 `HISTSIZE` 设置历史记录数量

### 显示历史命令时间戳
默认情况下，`history` 命令只显示命令列表，没有时间戳。可以通过设置 `HISTTIMEFORMAT` 环境变量来显示命令执行的时间：

```bash
# 设置时间格式（年-月-日 时:分:秒）
export HISTTIMEFORMAT='%F %T'

# 之后执行 history 命令，会显示带时间戳的历史记录
history
```

## 常用操作
```bash
history                  # 查看所有历史命令
history | grep "ls"      # 搜索包含 "ls" 的历史命令
!!                       # 执行上一条命令
!100                     # 执行历史第 100 条命令
!ls                      # 执行最近一条以 ls 开头的命令
```
