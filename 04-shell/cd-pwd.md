# cd / pwd

## 常用场景
- 切换工作目录
- 显示当前路径
- 导航文件系统

## cd 命令

### 功能
在使用 Unix/Linux 的时候，经常需要更换工作目录。cd 命令可以帮助用户切换工作目录。

### 重要提示
Linux 所有的目录和文件名大小写敏感。

### 命令格式
```bash
cd [-L|-P] [dir]
```

### 选项说明
- `-L`: （默认值）如果要切换到的目标目录是一个符号连接，那么切换到符号连接的目录
- `-P`: 如果要切换到的目标目录是一个符号连接，那么切换到它指向的物理位置目录

### 参数说明
- `dir (可选)`: 指定要切换到的目录，可以是绝对路径（以根目录为参照物）或相对路径（以当前目录为参照物）

### 使用方式
cd 后面可跟绝对路径，也可以跟相对路径。如果省略目录，则默认切换到当前用户的主目录。

### 常用命令

| 命令 | 含义 |
|------|------|
| `cd` | 切换到当前用户的主目录(/home/用户目录)，用户登陆的时候，默认的目录就是用户的主目录 |
| `cd ~` | 切换到当前用户的主目录(/home/用户目录) |
| `cd .` | 切换到当前目录 |
| `cd ..` | 切换到上级目录 |
| `cd -` | 可进入上一个进入的目录 |
| `cd /path/to/dir` | 切换到绝对路径 |
| `cd relative/path` | 切换到相对路径 |

### 路径说明
- **绝对路径**：如果路径是从根路径开始的，则路径的前面需要加上 `/`，如 `/mnt`
- **相对路径**：通常进入某个目录里的文件夹，前面不用加 `/`

### 示例
```bash
cd                      # 回到主目录
cd ~                    # 回到主目录
cd /home/user           # 切换到绝对路径
cd Documents            # 切换到相对路径
cd ..                   # 回到上一级目录
cd -                    # 回到上一个目录
```

## pwd 命令

### 功能
使用 pwd 命令可以显示当前的工作目录，该命令很简单，直接输入 pwd 即可，后面不带参数。

### 命令格式
```bash
pwd [参数选项]
```

### 常用参数
- `-L, --logical`: 打印环境变量 `$PWD` 的值，可能为符号链接
- `-P, --physical`: 打印当前工作目录的物理位置；Bash 内建 `pwd` 默认使用 `-L`
- `--help`: 显示帮助信息并退出
- `--version`: 显示版本信息并退出

### 参数说明
- `-P`: 如果是链接目录，则输出真实的目录
- `-L`: 目录是连接链接时，输出连接路径

### 常用命令
```bash
pwd                     # 显示当前工作目录
pwd -P                  # 显示物理路径
pwd -L                  # 显示逻辑路径（可能包含符号链接）
```

## 易错点
- Linux 目录和文件名大小写敏感
- 绝对路径以 `/` 开头，相对路径不需要
- `cd -` 可以快速回到上一个目录
- `cd` 不带参数时回到主目录

## 实战示例
```bash
# 显示当前路径
pwd

# 切换目录
cd /var/log
cd ~
cd Documents
cd ..

# 回到上一个目录
cd -
```
