# 正则表达式基础

## 常用场景
- grep / sed / awk 中使用
- 模式匹配

## 基础元字符
- `.`: 匹配任意字符
- `*`: 前一个字符 0 次或多次
- `+`: 前一个表达式 1 次或多次（扩展正则；`grep -E`）
- `?`: 前一个表达式 0 次或 1 次（扩展正则；`grep -E`）
- `^`: 行首
- `$`: 行尾

## 字符类
- `[abc]`: 匹配 a、b 或 c
- `[0-9]`: 匹配数字
- `[a-z]`: 匹配小写字母
- `[^abc]`: 不匹配 a、b、c

## 分组和引用
- `()`: 扩展正则中的分组；`sed` 默认基本正则使用 `\(` 和 `\)`
- `\1`: 在支持反向引用的语法中引用第一个捕获组；具体支持情况取决于工具

## 实战示例
```bash
grep "^[0-9]" file
sed 's/\(.*\)/\1/g' file
```
