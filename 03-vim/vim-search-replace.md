# Vim 搜索和替换

## 常用场景
- 查找文本
- 批量替换
- 快速定位

## 搜索功能

### 基本搜索
- `/字符串`: 向下搜索指定字符串
- `?字符串`: 向上搜索指定字符串（反向搜索）
- `n`: 寻找下一个匹配项
- `N`: 回到前一个匹配项（与当前搜索方向相反）

### 搜索当前单词
- `*`: 搜索当前光标下的单词（向下）
- `#`: 反向搜索当前光标下的单词（向上）

### 高级搜索模式
- `/^字符串`: 查找以字符串开始的行
- `/字符串$`: 查找以字符串结尾的行
- `/a.b`: 查找字符串 a 任意字符 b（`.` 匹配任意字符）

### 搜索修饰符
- `\c`: 忽略大小写匹配（例如 `/搜索词\c`）
- `\C`: 区分大小写匹配

### 搜索步骤
1. 按下 `/` 键进入搜索模式（底部状态栏会显示斜杠）
2. 输入要搜索的字符串
3. 按回车键开始搜索
4. 使用 `n` 继续查找下一个，使用 `N` 查找上一个
5. 按 `Esc` 退出搜索模式

## 替换功能

### 字符替换
- `r`: 替换当前光标下的字符（输入新字符即可）

### 行内替换
- `:s/p1/p2/`: 将当前行中第一个 p1 替换为 p2
- `:s/p1/p2/g`: 将当前行中所有 p1 均用 p2 替代

### 全文替换
- `:g/p1/s//p2/g`: 将文件中所有 p1 均用 p2 替代
- `:%s/p1/p2/g`: 替换全文（与上面等价）

### 指定范围替换
- `:n1,n2s/p1/p2/g`: 将 n1 到 n2 行中所有 p1 均用 p2 替代

### 替换标志
- `g`: 全局（一行内所有匹配）
- `c`: 确认（每次替换前询问）
- `i`: 忽略大小写

## 载入文件
- `:r 文件名`: 在光标当前位置载入另一个文件的内容

## 实战示例
```vim
" 替换 IP 地址
:%s/127\.0\.0\.1/localhost/g

" 删除行首注释符号
:%s/^#//g

" 替换时确认
:%s/old/new/gc

" 替换指定行范围
:10,20s/old/new/g

" 忽略大小写搜索
/pattern\c
```
