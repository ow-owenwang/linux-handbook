# ln

## 常用场景
- 创建链接文件
- 创建快捷方式
- 文件引用

## 功能
建立链接文件

## 链接类型

### 软链接（符号链接）
- Linux 链接文件类似于 Windows 下的快捷方式
- 软链接不占用磁盘空间
- 源文件删除则软链接失效
- 可以链接文件和目录

### 硬链接
- 硬链接只能链接普通文件，不能链接目录
- 两个文件占用相同大小的硬盘空间
- 即使删除了源文件，链接文件还是存在
- 硬链接和源文件指向同一个 inode

## 使用格式
```bash
ln 源文件 链接文件              # 创建硬链接
ln -s 源文件 链接文件           # 创建软链接
```

## 常用命令
```bash
ln file linkfile               # 创建硬链接
ln -s file linkfile            # 创建软链接
ln -s /path/to/file linkfile   # 创建软链接（使用绝对路径）
```

## 常用参数
- `-s`: 创建软链接（符号链接），如果没有 `-s` 选项代表建立一个硬链接文件

## 注意事项
- 如果软链接文件和源文件不在同一个目录，源文件要使用绝对路径，不能使用相对路径
- 软链接更常见，因为可以链接目录
- 硬链接不能跨文件系统
- 删除源文件后，软链接失效，硬链接仍然可用

## 易错点
- 软链接使用相对路径可能导致链接失效
- 硬链接不能用于目录
- 删除源文件对软链接和硬链接的影响不同

## 实战示例
```bash
# 创建软链接
ln -s /usr/bin/python3 /usr/local/bin/python

# 创建硬链接
ln file.txt hardlink.txt

# 查看链接
ls -l linkfile

# 删除链接（不影响源文件）
rm linkfile
```
