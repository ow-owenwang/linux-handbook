# Linux 知识库

这是一个按使用场景组织的 Linux 学习笔记和速查知识库。

## 📚 目录结构

```
linux-handbook/
├── 00-intro/              # 入门介绍
├── 01-filesystem/         # 文件系统
├── 02-commands/           # 命令分类
│   ├── file/              # 文件操作
│   ├── text/              # 文本处理
│   ├── process/           # 进程管理
│   ├── network/           # 网络工具
│   ├── system-info/       # 系统信息
│   └── package/           # 包管理
├── 03-vim/                # Vim 编辑器
├── 04-shell/              # Shell 脚本
├── 05-system/             # 系统管理
├── 06-network/            # 网络配置
├── 07-troubleshooting/    # 故障排查
├── 08-best-practices/     # 最佳实践
├── 09-containers/         # 容器技术
├── 10-version-control/    # 版本控制
├── cheatsheet.md          # 速查表
└── README.md              # 本文件
```

## 🎯 使用方式

1. **按需查找**：根据使用场景查找对应目录
2. **快速参考**：查看 [cheatsheet.md](./cheatsheet.md) 速查表
3. **系统学习**：从 `00-intro` 开始，按顺序阅读

## 📝 笔记格式

多数笔记按以下要点组织，具体小节随主题调整：
- **常用场景**：什么情况下使用
- **常用命令**：实际命令示例
- **常用参数**：重要参数说明
- **易错点**：容易出错的地方
- **实战示例**：真实使用场景
- **延伸阅读**：相关笔记链接

## 🔍 如何查找

- **想找命令**：查看 `02-commands/` 下对应分类
- **想学 Vim**：查看 `03-vim/` 目录
- **遇到问题**：查看 `07-troubleshooting/` 目录
- **快速参考**：直接看 `cheatsheet.md`

## 💡 原则

- **按使用场景组织**，不是按书本章节
- **常用、速查的** → 扁平、好找
- **系统性的、原理性的** → 层级清晰
- **容易忘、但常用的** → 独立出来

## 📖 开始使用

建议从以下文件开始：
1. [00-intro/common-paths.md](./00-intro/common-paths.md) - 了解常用路径
2. [cheatsheet.md](./cheatsheet.md) - 快速参考
3. 根据你的需求，查找对应目录
