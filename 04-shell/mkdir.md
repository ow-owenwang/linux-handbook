# mkdir

## 常用场景
- 创建新目录
- 创建多级目录

## 功能
通过 mkdir 命令可以创建一个新的目录。

## 常用命令
```bash
mkdir dirname            # 创建单个目录
mkdir -p dir1/dir2/dir3  # 递归创建目录
mkdir dir1 dir2 dir3     # 创建多个目录
```

## 常用参数
- `-p`: 可递归创建目录（如果父目录不存在，会先创建父目录）

## 注意事项
- 新建目录的名称不能与当前目录中已有的目录或文件同名
- 目录创建者必须对当前目录具有写权限
- 使用 `-p` 参数可以创建多级目录，即使中间目录不存在

## 易错点
- 创建多级目录时必须使用 `-p` 参数
- 没有写权限会创建失败
- 目录名不能与现有文件或目录同名

## 实战示例
```bash
# 创建单个目录
mkdir test

# 创建多级目录
mkdir -p project/src/main

# 创建多个目录
mkdir dir1 dir2 dir3

# 创建带权限的目录（需要配合 chmod）
mkdir -p /var/www/html
```
