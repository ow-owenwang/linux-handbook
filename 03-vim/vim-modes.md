# Vim 模式

## 常用场景
- 理解 Vim 的工作方式
- 在不同模式间切换

## 主要模式

### Normal 模式（普通模式）
- 默认模式
- 用于导航和命令

### Insert 模式（插入模式）
- `i`: 当前位置插入
- `a`: 当前位置后插入
- `o`: 下一行插入
- `I`: 行首插入
- `A`: 行尾插入

### Visual 模式（可视模式）
- `v`: 字符选择（进入字符可视模式）
- `V`: 行选择（进入行可视模式）
- `Ctrl+v`: 块选择（进入列模式，用于多行注释等）

#### 可视模式下的操作
- 选择文本后，可以：
  - `y`: 复制选中的文本
  - `d`: 删除选中的文本
  - `c`: 删除并进入插入模式
  - `p`: 粘贴（替换选中的文本）

### Command 模式（命令模式）
- `:`: 进入命令模式
- 执行保存、退出等命令

## 模式切换
- `Esc`: 返回 Normal 模式
- `i/a/o`: 进入 Insert 模式
- `v/V`: 进入 Visual 模式
