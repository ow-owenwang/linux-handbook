# 常用路径

## 常用场景
- 快速查找配置文件位置
- 理解系统目录结构

## 重要目录

### /etc
- 配置文件
- 不放可执行程序
- systemd、nginx、ssh 配置都在这里

### /var
- 经常变化的数据
- log / spool / cache

### /usr
- 用户空间程序
- /usr/bin / /usr/lib

### /home
- 用户主目录

### /tmp
- 临时文件

### /opt
- 可选软件包

### /root
- root 用户主目录
