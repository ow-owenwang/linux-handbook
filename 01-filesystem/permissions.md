# 文件权限

## 常用场景
- 理解文件权限
- 查看文件权限
- 理解权限的作用

## 文件权限概述

### 什么是文件权限
文件权限就是文件的访问控制权限，即哪些用户和组群可以访问文件以及可以执行什么样的操作。

Unix/Linux 系统是一个典型的多用户系统，不同的用户处于不同的地位，对文件和目录有不同的访问权限。为了保护系统的安全性，Unix/Linux 系统除了对用户权限作了严格的界定外，还在用户身份认证、访问控制、传输安全、文件读写权限等方面作了周密的控制。

在 Unix/Linux 中的每一个文件或目录都包含有访问权限，这些访问权限决定了谁能访问和如何访问这些文件和目录。

## 访问用户

### 三种访问方式
通过设定权限可以从以下三种访问方式限制访问权限：

#### 1. 只允许用户自己访问（所有者）
所有者就是创建文件的用户，用户是所有用户所创建文件的所有者，用户可以允许所在的用户组能访问用户的文件。

#### 2. 允许一个预先指定的用户组中的用户访问（用户组）
用户都组合成用户组，例如，某一类或某一项目中的所有用户都能够被系统管理员归为一个用户组，一个用户能够授予所在用户组的其他成员的文件访问权限。

#### 3. 允许系统中的任何用户访问（其他用户）
用户也将自己的文件向系统内的所有用户开放，在这种情况下，系统内的所有用户都能够访问用户的目录或文件。在这种意义上，系统内的其他所有用户就是 other 用户类。

### 类比说明
这有点类似于 QQ 空间的访问权限：
- 这个 QQ 空间是属于我的，我相当于管理者（也就是"所有者"），我想怎么访问就怎么访问
- 同时，我可以设置允许 QQ 好友访问，而这些 QQ 好友则类似于"用户组"
- 当然，我可以允许所有人访问，这里的所有人则类似于"其他用户"

## 访问权限

### 三种基本权限
用户能够控制一个给定的文件或目录的访问程度，一个文件或目录可能有读、写及执行权限：

#### 读权限（r）
- **对文件而言**：具有读取文件内容的权限
- **对目录来说**：可以读取目录项名称；列出条目及访问其元数据通常还需要 `x`

#### 写权限（w）
- **对文件而言**：具有新增、修改文件内容的权限
- **对目录来说**：配合 `x` 可创建、删除或重命名目录项；删除文件主要取决于父目录权限，还可能受 sticky bit 等限制

#### 可执行权限（x）
- **对文件而言**：具有执行文件的权限
- **对目录来说**：可以穿越目录、访问已知名称的目录项；读取目录项名称还需 `r`

### 注意事项
通常，Unix/Linux 系统只允许文件的属主(所有者)或超级用户改变文件的读写权限。

## 权限表示

### ls -l 输出说明
使用 `ls -l` 命令查看文件权限时，输出格式如下：
```
-rwxr-xr-x 1 user group 1024 Jan 1 12:00 file.txt
drwxr-xr-x 2 user group 4096 Jan 1 12:00 directory
```

### 权限位说明
1. **第 1 个字母**代表文件的类型：
   - `d` 代表文件夹（目录）
   - `-` 代表普通文件
   - `c` 代表硬件字符设备
   - `b` 代表硬件块设备
   - `s` 表示套接字（socket）
   - `l` 代表软链接文件（符号链接）
   - `p` 代表命名管道（FIFO）

2. **后 9 个字母**分别代表三组权限：文件所有者、用户组、其他用户拥有的权限

### 权限分组
每一个用户都有它自身的读、写和执行权限。
- **第一组权限**（前 3 位）：控制访问自己的文件权限，即所有者权限
- **第二组权限**（中间 3 位）：控制用户组访问其中一个用户的文件的权限
- **第三组权限**（后 3 位）：控制其他所有用户访问一个用户的文件的权限

这三组各有 `rwx` 三个位，共九个基本权限位。访问时按所有者、所属组、其他用户依次匹配一类，并非把三类权限相加。

## 常用命令
```bash
ls -l                    # 查看文件权限
stat file                # 查看文件详细信息
```

## 权限说明
- r (read): 4
- w (write): 2
- x (execute): 1
- 所有者、组、其他用户
