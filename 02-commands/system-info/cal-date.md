# cal / date

## 常用场景
- 查看日历
- 显示系统时间
- 设置系统时间

## cal 命令

### 功能
查看当前日历

### 常用命令
```bash
cal                 # 查看当前月份日历
cal -y              # 显示整年日历
cal 2024            # 显示指定年份的日历
cal 12 2024         # 显示指定年月的日历
```

### 常用参数
- `-y`: 显示整年日历
- `-3`: 显示系统前一个月、当前月、下一个月的日历

### 使用示例
```bash
cal                 # 显示本月日历
cal -3              # 显示前一个月、当前月、下一个月的日历
cal 2022            # 显示指定年份的日历
cal 12 2024         # 显示指定年月的日历
```

## date 命令

### 功能
显示或设置系统时间

### 显示时间

#### 基本用法
```bash
date                # 显示当前时间
date '+%Y-%m-%d %H:%M:%S'    # 自定义格式显示
```

#### 格式说明
format 格式参数：

| 格式 | 含义 |
|------|------|
| `%Y` | 年（4位数字） |
| `%y` | 年（2位数字） |
| `%m` | 月 |
| `%d` | 日 |
| `%H` | 时（24小时制） |
| `%M` | 分 |
| `%S` | 秒 |

#### 常用格式示例
```bash
date '+%Y,%m,%d,%H,%M,%S'    # 输出：2024,01,15,14,30,45
date '+%Y-%m-%d %H:%M:%S'    # 输出：2024-01-15 14:30:45
```

### 设置时间

#### 方法一：使用 -s 参数（推荐）
```bash
date -s "字符串时间"
```

**示例**：
```bash
sudo date -s "2022-05-20 20:52:18"
```

#### 方法二：使用传统格式
```bash
date [MMDDhhmm[[CC]YY][.ss]]
```

#### 格式说明
- **CC**: 年前两位（世纪）
- **YY**: 年的后两位
- **MM**: 月（前两位）
- **DD**: 天
- **hh**: 小时
- **mm**: 分钟（后两位）
- **ss**: 秒

#### 设置示例
```bash
# 使用 -s 参数（推荐，更直观）
sudo date -s "2022-05-20 20:52:18"

# 使用传统格式
sudo date 010203042016.55      # 2016年1月2日 03:04:55
sudo date 122520302024.00      # 2024年12月25日 20:30:00
```

### 注意事项
- 注意命令与参数之间有空格
- 使用格式字符串时，注意 `date +"%Y-%m-%d"` 中 `date` 后面有个空格再加
- 使用 `date "+%Y-%m-%d %H:%M:%S"` 时，注意 `%d` 和 `%H` 之间有空格
- 显示的是字符串描述的时间，不是当前时间（使用格式字符串时）

### 易错点
- 设置时间需要管理员权限（使用 sudo）
- 时间格式必须严格按照 MMDDhhmmCCYY.ss 格式
- 设置错误的时间可能导致系统问题

## 实战示例
```bash
# 查看日历
cal
cal -y

# 显示时间
date
date '+%Y-%m-%d %H:%M:%S'

# 设置时间（需要 root 权限）
sudo date 010203042016.55
```
