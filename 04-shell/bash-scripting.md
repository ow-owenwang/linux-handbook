# Bash 脚本

## 常用场景
- 自动化任务
- 批量处理
- 系统配置和管理
- 文本处理
- 网络操作
- 日志和错误处理

## Bash 脚本可以做什么

1. **自动化任务**：你可以编写 Bash 脚本来自动执行重复性任务，比如备份文件、定期清理旧文件、定时运行任务等
2. **文件和目录操作**：Bash 脚本可以帮你批量重命名文件、移动文件、删除文件，或者在多个文件中查找和替换文本
3. **系统配置和管理**：你可以使用 Bash 脚本来配置系统参数、安装软件包、管理用户和权限等
4. **文本处理**：Bash 脚本非常擅长处理文本文件。你可以使用脚本来解析、分割、排序、过滤、统计文本文件中的内容
5. **网络操作**：你可以编写脚本来进行网络连接、下载文件、发送 HTTP 请求、检测网络服务的可用性等
6. **日志和错误处理**：Bash 脚本可以用于处理日志文件，提取关键信息，或者在脚本出错时发送通知
7. **环境变量和用户输入处理**：你可以编写脚本来读取和设置环境变量，以及接收用户输入，从而使脚本更加灵活和可配置
8. **条件判断和循环**：Bash 脚本支持条件判断和循环结构，使得你可以编写复杂的逻辑，根据不同的条件执行不同的操作
9. **函数和模块化编程**：你可以将 Bash 脚本分解为多个函数，实现模块化编程，提高代码的可读性和可维护性
10. **系统监控和报警**：你可以编写脚本来监控系统性能、资源利用率，当系统达到某些阈值时触发报警

## 脚本基础

### Shebang (Hashbang)
脚本第一行指定解释器，使用 `#!` 开头。

```bash
#!/bin/bash
# 脚本第一行指定解释器
```

### Shebang 说明
Shebang（或 Hashbang）是一种特殊的注释，通常位于脚本文件的第一行，用于指示操作系统如何执行该脚本。其格式为 `#!`，后面紧跟解释器的路径。

**格式示例**：
```bash
#!/bin/bash              # 使用 Bash 解释器
#!/usr/bin/env python    # 使用 Python 解释器（推荐，更灵活）
#!/usr/bin/env node      # 使用 Node.js 解释器
```

**功能**：
- 指定脚本的解释器，确保脚本以正确的环境运行
- 使得用户可以直接运行脚本文件，而无需显式调用解释器

**使用场景**：
- 在 Web 开发中，shebang 常用于重定向请求到特定的脚本或程序
- 在 Web 服务器配置中，shebang 也可以用来指定处理特定文件类型的脚本

## 常用语法
- 变量: `VAR=value`, `$VAR`
- 条件: `if [ condition ]; then ... fi`
- 循环: `for`, `while`
- 函数: `function_name() { ... }`

## 逻辑运算符

### && (逻辑与)
命令之间使用 `&&` 连接，实现逻辑与的功能。

```bash
# 只有在 && 左边的命令返回真（命令返回值 $? == 0），&& 右边的命令才会被执行
# 只要有一个命令返回假（命令返回值 $? == 1），后面的命令就不会被执行
mkdir test && cd test
```

**示例**：
```bash
# 如果 mkdir 成功，则执行 cd
mkdir test && cd test

# 如果命令1成功，则执行命令2
command1 && command2
```

## 实战示例
```bash
#!/bin/bash
for file in *.log; do
    echo "Processing $file"
done

# 使用 && 连接命令
mkdir test && cd test && touch file.txt
```
