# wc

## 常用场景
- 统计文件行数
- 统计文件字数
- 统计文件字节数
- 文本统计

## 功能
计算文件行数或字数

## 常用命令
```bash
wc file                  # 显示行数、字数、字节数
wc -l file               # 只显示行数
wc -w file               # 只显示字数
wc -c file               # 只显示字节数
wc -m file               # 只显示字符数
```

## 常用选项说明

| 选项 | 含义 |
|------|------|
| `-l` | 统计行数 |
| `-w` | 统计字数。一个字被定义为由空白、跳格或换行字符分隔的字符串 |
| `-c` | 统计字节数 |
| `-m` | 统计字符数。这个标志不能与 -c 标志一起使用 |

## 输出格式
默认情况下，wc 输出三个数字：
- 行数
- 字数
- 字节数

## 易错点
- `-m` 和 `-c` 标志不能一起使用
- 字数统计以空白、跳格或换行字符分隔
- 可以同时统计多个文件

## 实战示例
```bash
# 统计文件
wc file.txt
wc -l file.txt           # 只统计行数
wc -w file.txt           # 只统计字数
wc -c file.txt           # 只统计字节数

# 统计多个文件
wc *.txt

# 结合管道使用
cat file.txt | wc -l
ls | wc -l               # 统计文件数量
```
