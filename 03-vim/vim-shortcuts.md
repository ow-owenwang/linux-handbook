# Vim 快捷键

## 常用场景
- 快速编辑
- 提高效率

## 光标移动

### 基本移动
- `h/j/k/l`: 左/下/上/右
- `w`: 向前移动一个词（以词的开头为准）
- `b`: 向后移动一个词（以词的开头为准）
- `e`: 向前移动到一个词的末尾

### 行内移动
- `0`: 将光标移动到当前行的行首（第一个字符处）
- `^`: 将光标移动到当前行的第一个非空格字符处
- `$`: 将光标移动到当前行的行尾
- `g_`: 将光标移动到当前行的最后一个非空格字符处

### 文件内移动
- `gg`: 将光标移动到文件的开头
- `G`: 将光标移动到文件的末尾
- `nG` 或 `ngg`: 将光标移动到第 n 行（例如 `100G` 跳转到第 100 行）
- `:$`: 到文件最后一行行首

### 屏幕滚动
- `Ctrl+f`: 向前滚动一个屏幕
- `Ctrl+b`: 向后滚动一个屏幕

## 删除操作

### 字符删除
- `[n]x`: 删除光标后 n 个字符（默认 1 个）
- `[n]X`: 删除光标前 n 个字符（默认 1 个）
- `D`: 删除光标所在位置到此行尾的所有字符

### 行删除
- `[n]dd`: 删除从当前行开始的 n 行（准确来讲是剪切，剪切不粘贴即为删除）
- `dG`: 删除光标所在行开始到文件尾的所有字符
- `.,$d`: 删除当前行和之后的所有内容
- `.,100d`: 删除当前行到第 100 行的内容
- `10,$d`: 删除第 10 行到文件行尾的内容
- `%d`: 删除所有行内容

## 复制和粘贴

### 复制
- `[n]yy`: 复制从当前行开始的 n 行
- `y`: 在可视模式下复制选中的文本

### 粘贴
- `p`: 把粘贴板上的内容插入到当前行（光标后）
- `P`: 把粘贴板上的内容插入到当前行（光标前）

### 可视模式复制多行
1. 移动光标到起始位置
2. 按 `V`（大写）进入行可视模式
3. 使用方向键选择多行
4. 按 `y` 复制
5. 移动光标到目标位置，按 `p` 粘贴

### 可视模式复制文本块
1. 移动光标到起始位置
2. 按 `v` 进入字符可视模式
3. 使用方向键选择文本块
4. 按 `y` 复制
5. 移动光标到目标位置，按 `p` 粘贴

## 编辑操作

### 撤销和重做
- `u`: 撤销前一个命令
- `Ctrl+r`: 重做
- `.`: 执行上一次操作（重复上一次命令）

### 合并行
- `J`: 合并当前行和下一行（删除换行符）

## 多行注释

### 添加注释
1. 按 `Ctrl+v` 进入列模式（块选择）
2. 使用方向键选中需要注释的行
3. 按大写的 `I` 进入插入模式
4. 输入注释符号（如 `#` 或 `//`）
5. 按 `Esc`，所有选中的行都会添加注释

### 取消注释
1. 按 `Ctrl+v` 进入列模式
2. 选中要删除的注释符号列
3. 按 `d` 删除即可

### 使用替换命令注释/取消注释
```vim
:27,30s#^#//#g          " 在 27-30 行行首添加 //
:27,30s#^//##g          " 删除 27-30 行行首的 //
:10,20s/^/#/g           " 在 10-20 行行首添加 #
```
