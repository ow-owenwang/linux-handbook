# Git 基础

## 常用场景
- 版本控制
- 代码管理
- 协作开发

## 常用命令
```bash
git clone url
git add file
git commit -m "message"
git push
git pull
git status
```

## 基础概念
- Repository: 仓库
- Commit: 提交
- Branch: 分支
- Remote: 远程仓库

## 实战示例
```bash
git clone https://github.com/user/repo.git
git add .
git commit -m "Initial commit"
git push origin main
```
