# ps / top / htop

## 常用场景
- 查看进程
- 监控系统资源
- 动态监控进程状态

## ps 命令

### 常用命令
```bash
ps -a          # 显示终端上的所有进程，包括其他用户的进程
ps aux         # BSD 风格选项：显示所有用户进程的详细状态
ps -ef         # 另一种格式显示所有进程
```

### 常用参数
- `-a`: 显示终端上的所有进程，包括其他用户的进程
- `u`（BSD 风格）：按用户导向格式显示；`x` 包括无控制终端的进程。与带短横线的 POSIX 风格选项不要随意混写
- `-w`: 显示加宽，以便显示更多的信息
- `-r`: 只显示正在运行的进程

### 进程概念
进程是一个具有一定独立功能的程序，它是操作系统动态执行的基本单元。

## top 命令

### 常用命令
```bash
top                    # 动态显示运行中的进程
top -d 5               # 指定更新间隔为 5 秒
```

### 常用参数
- `-d <interval>`: 指定显示信息更新的时间间隔（秒）

### top 交互式按键
在 top 命令执行后，可以按下按键对显示结果进行排序和操作：

- `M`: 根据内存使用量来排序
- `P`: 根据 CPU 占有率来排序
- `T`: 根据进程运行时间的长短来排序
- `U`: 可以根据后面输入的用户名来筛选进程
- `K`: 可以根据后面输入的 PID 来杀死进程
- `q`: 退出
- `h`: 获得帮助

## htop 命令

```bash
htop    # 更友好的 top 替代品
```

## 易错点
- ps aux 和 ps -ef 输出格式不同
- top 中按 q 退出，不是 Ctrl+C
- top 默认按 CPU 使用率排序

## 实战示例
```bash
ps aux | grep nginx
ps -a | grep python
top -d 2
top -p 1234
```
