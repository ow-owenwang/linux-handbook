在 macOS（Linux 也一样）中，最常用的是 `cp -R` 或 `rsync`。

### 方式一：cp -R（简单）

```bash
cp -R 源目录/* 目标目录/
```

例如：

```bash
cp -R /Users/ginkgo/source/* /Users/ginkgo/target/
```

作用：

- 递归复制 `source` 目录下的所有文件和子目录
- 不会复制 `source` 目录本身
- 会复制隐藏文件以外的大部分内容

---

### 方式二：复制包括隐藏文件

如果目录里有 `.git`、`.env` 等隐藏文件：

```bash
cp -R /Users/ginkgo/source/. /Users/ginkgo/target/
```

注意最后的 `.`：

```text
source/.
```

表示复制目录中的全部内容（包含隐藏文件）。

---

### 方式三：推荐 rsync

实际开发中更推荐：

```bash
rsync -av /Users/ginkgo/source/ /Users/ginkgo/target/
```

参数：

- `-a`：保持权限、时间等属性
- `-v`：显示复制过程

示例：

```bash
rsync -av ./dist/ ./backup/
```

特点：

- 支持增量复制
- 速度快
- 能保留文件属性
- 大量文件时比 `cp` 更稳定

---

### 方式四：覆盖已有文件

```bash
rsync -av --delete source/ target/
```

例如：

```bash
rsync -av --delete ./build/ ./deploy/
```

作用：

- 目标目录与源目录保持完全一致
- 源目录删除的文件，目标目录也会删除
