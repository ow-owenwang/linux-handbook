# df / du

## 常用场景
- 查看磁盘使用情况
- 查找大文件
- 检测磁盘空间占用

## df 命令

### 功能
df 命令用于检测文件系统的磁盘空间占用和空余情况，可以显示所有文件系统对节点和磁盘块的使用情况。

### 常用命令
```bash
df -h                 # 人类可读格式
df -m                 # 以 1 MiB（1024² 字节）为单位显示
df -a                 # 显示所有文件系统的磁盘使用情况
df -T                 # 显示文件系统类型
df -t ext4            # 显示指定文件系统类型的磁盘空间使用情况
```

### 常用参数
- `-a`: 显示所有文件系统的磁盘使用情况
- `-m`: 以 1 MiB 为单位显示
- `-h`: 以人类可读格式显示（KB, MB, GB）
- `-t <fs>`: 显示各指定文件系统的磁盘空间使用情况
- `-T`: 显示文件系统类型

## du 命令

### 功能
du 命令用于统计目录或文件所占磁盘空间的大小，该命令的执行结果与 df 类似，du 更侧重于磁盘的使用状况。

### 使用格式
```bash
du [选项] 目录或文件名
```

### 常用命令
```bash
du -sh *              # 显示当前目录各文件/目录大小
du -h --max-depth=1   # 显示一级子目录大小
du -s /home           # 显示指定目录总大小
du -a                 # 递归显示所有文件和子目录大小
du -b                 # 以字节为单位显示
```

### 常用参数
- `-a`: 递归显示指定目录中各文件和子目录中文件占用的数据块
- `-s`: 显示指定文件或目录占用的数据块（只显示总计）
- `-b`: GNU du 中相当于 `--apparent-size --block-size=1`，显示表观大小，不等于实际分配的磁盘空间
- `-h`: 以人类可读格式显示
- `-l`: 计算所有文件大小，对硬链接文件计算多次
- `--max-depth=n`: 显示目录深度

## 区别
- **df**: 显示文件系统的使用情况（整个分区）
- **du**: 显示目录或文件的使用情况（具体文件/目录）

## 易错点
- df 显示文件系统使用，du 显示目录使用
- du 默认递归显示，使用 `-s` 只显示总计
- 需要 root 权限查看某些系统目录

## du 常用选项补充
- `-h`: 以人类可读的格式显示文件大小
- `-s`: 仅显示总大小，不显示子目录的详细信息
- `-a`: 显示每个文件的大小，包括子目录中的文件
- `--max-depth=N`: 限制递归深度，显示指定深度内的目录大小

## 实战示例
```bash
# 查看磁盘使用
df -h
sudo df -m

# 查看目录大小
du -h                    # 显示当前目录及子目录大小
du -sh                   # 只显示总大小
du -h --max-depth=1      # 显示一级子目录大小
du -sh /var/log/*
du -h --max-depth=1 /home
sudo du -s /home

# 查找大文件
du -h | sort -h | tail -10
```
