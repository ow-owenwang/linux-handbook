# clear

## 常用场景
- 清屏
- 清除终端显示
- 清理屏幕内容

## 功能
clear 作用为清除终端上的显示（类似于 DOS 的 cls 清屏功能）

## 常用命令
```bash
clear                   # 清除终端显示
```

## 快捷键
也可以使用快捷键：`Ctrl + l`（"l" 为字母）

## 说明
- clear 命令会清除当前终端屏幕的所有内容
- 使用后光标会移动到屏幕顶部
- 不会影响命令历史

## 易错点
- clear 只是清除显示，不会删除命令历史
- 使用 `Ctrl + l` 快捷键更方便
- 在某些终端中，clear 和 `Ctrl + l` 效果相同

## 实战示例
```bash
# 清屏
clear

# 或使用快捷键
# Ctrl + l
```
