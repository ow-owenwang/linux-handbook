# 管道和重定向

## 常用场景
- 组合命令
- 保存输出
- 错误处理
- 分屏显示

## 输出重定向

### 基本用法
Linux 允许将命令执行结果重定向到一个文件，本应显示在终端上的内容保存到指定文件中。

```bash
command > file        # 输出重定向（覆盖）
command >> file       # 输出重定向（追加）
```

### 重定向说明
- `>`: 输出重定向会覆盖原来的内容
- `>>`: 输出重定向则会追加到文件的尾部
- 如果文件不存在，则创建；如果存在，`>` 会覆盖，`>>` 会追加

### 示例
```bash
ls > test.txt         # 将 ls 的输出保存到 test.txt（覆盖）
ls >> test.txt        # 将 ls 的输出追加到 test.txt
```

## 输入重定向
```bash
command < file        # 输入重定向，从文件读取输入
```

## 错误重定向
```bash
command 2> file       # 错误重定向
command 2>&1          # 错误合并到标准输出
```

## 管道

### 功能
管道：一个命令的输出可以通过管道做为另一个命令的输入。

### 理解
管道我们可以理解现实生活中的管子，管子的一头塞东西进去，另一头取出来，这里 `|` 的左右分为两端，左端塞东西(写)，右端取东西(读)。

### 常用命令
```bash
command1 | command2
ls -alh | more        # 将 ls 的输出通过管道传给 more 分屏显示
ps aux | grep nginx
```

## 常用组合
```bash
command > file 2>&1           # 标准输出和错误都重定向到文件
command >> log.txt 2>&1       # 追加模式
ls -l | grep "\.txt" > files.txt
```

## 重定向符号说明

### > 和 >> 的区别
在 Linux 中，`>` 和 `>>` 被称为重定向符号（Redirection Operators）。

- `>`：用于将命令的输出重定向到指定文件并**覆盖**该文件的内容
- `>>`：用于将命令的输出**追加**到指定文件的末尾

**区别**：
- `ls -l > 1.txt`：这个命令会将 `ls -l` 的输出覆盖写入到 `1.txt` 文件中。如果 `1.txt` 文件已经存在，执行该命令将会覆盖原有内容，如果不存在则会创建这个文件并将输出写入其中
- `ls -l >> 1.txt`：这个命令会将 `ls -l` 的输出追加写入到 `1.txt` 文件中。如果 `1.txt` 文件已经存在，执行该命令会在文件末尾追加 `ls -l` 的输出，如果文件不存在则会创建这个文件并将输出写入其中

## 易错点
- `>` 覆盖，`>>` 追加
- `2>&1` 顺序很重要
- 重定向会创建文件（如果不存在）
- 管道连接多个命令，前一个的输出是后一个的输入
- 使用 `>` 会覆盖文件，重要数据要小心

## 实战示例
```bash
# 输出重定向
ls -l > filelist.txt
echo "hello" >> log.txt

# 管道
ls -alh | more
ps aux | grep nginx | head -10

# 组合使用
ls -l | grep "\.txt" > files.txt
command > output.log 2>&1
```
